# Scene Room workspace direction

A quiet editing suite: cool graphite chrome (#20252a), silver panels (#f0f2f3), white text fields, restrained teal controls (#237c7b), and red only for recording. System sans-serif for controls, tabular numbers for time and lenses. The live set is the central visual; no landing page, hero, decorative artwork or fake activity.

Layout: shot library and visual references at left, large camera view in the middle, lens and movement controls at right, transport and recorded takes below. A compact toolbar contains file operations. Operation and inspection are visibly different modes. Primary task is framing and recording a camera; advanced tools are secondary. Narrow screens stack controls without hiding save/replay.

The product should feel like part of a movie workflow, not a general 3D modelling application. Organize the experience around reference → set → shot → take → AI shot. Use filmmaking language such as shots, takes, lenses, framing, record, replay and generate. Keep object construction, geometry settings and coordinate editing in secondary, collapsible tools. The default camera view should prioritize composition over grids, gizmos and wireframes. Show a clear recording state and an easy route from a selected take to its generation references.

All controls must perform real state changes. Preserve original takes. Visible loading/error messages replace fabricated successful AI outcomes. Source image analysis and generation need verified real connections before completion.

## Accepted layout to preserve

The operator explicitly approved the current layout on 28 October 2026. Preserve the four directional images and six creative-shot slots. Do not replace or remove them when applying lessons from the supplied Nexus guides and videos. Recommend useful additions first; implement them as detail within existing shots or secondary controls, without an unsolicited redesign.

The four views establish geography. The six shots provide creative coverage ideas. A selected shot can later contain several temporal panels without replacing the six-shot overview. Distinguish a shot option from an ordered narrative sequence.

## Native macOS-inspired finish — 29 October 2026

Preserve the accepted filmmaking layout. Use system/SF typography, tabular time values, neutral silver surfaces, graphite chrome, restrained teal selection, consistent control radii and quiet separators. Provide visible keyboard focus, named icon controls, reduced-motion handling and readable secondary labels. This is an Apple-inspired finish, not a claim of official HIG certification.

Busy states must protect recording, playback and export from conflicting project/set/camera edits. Long sampled planned takes show one editable key at a time with previous/next controls rather than hundreds of simultaneous fields. No additional permanent panels or dependencies were introduced.

## Timing and preset discoverability — 29 October 2026

Timeline and take smoothing belong directly beneath the camera transport, before directional views/storyboard. Slow–Fast camera-speed sliders retime the same path: presets use6s at1×; existing takes use their saved duration at1×. Duration remains available for exact timing. Save variation preserves the original. The labeled camera movement preset library opens by default, with grouped movement buttons and an explicit Hide/Browse camera movements control; selecting a movement does not dismiss it.
